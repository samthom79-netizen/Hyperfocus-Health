---
title: How to edit page copy
description: Page text lives in this folder as Markdown so it can be edited without touching code.
---

Each page's words live here as a `.md` or `.mdx` file (for example `home.md`, `about.md`).

Rules for anyone editing:

- Keep paragraphs to 3 short sentences.
- Never name a medicine, brand or class of medicine.
- No testimonials, no superlatives, no promised outcomes.
- Write `[TODO: ...]` for anything you aren't sure of rather than guessing.

This README is excluded from the site.
